# LabApp - лабораторный практикум — локальное приложение для лабораторных работ студентов ТУСУРа.
====================================================================
Локальное веб-приложение для ввода данных эксперимента, автоматического
расчета и построения графиков.

Технологии
====================================================================
Flask (веб-интерфейс), numpy (расчёты и аппроксимация), matplotlib
(графики PNG), openpyxl (Excel-файлы .xlsx с диаграммами).

Возможности
====================================================================
• Главная страница: две сворачиваемые секции курсов (аккордеоны). В шапке —
  только «Лабораторный практикум». Каждая работа открывается в новой вкладке.
• «Расчетная часть» — во всех работах под блоком формул выводится таблица
  «формула = подстановка = ответ» со всеми расчётами: построчные вычисления
  (I_pn, I/I0, arcsin√(I/I0), τ, …), суммы и коэффициенты МНК (k, b, R²),
  итоговые величины (I_пор, U_λ/2, r_33, τ опорное, линейный диапазон).
  Длинные таблицы прокручиваются внутри панели.

• Курс «Квантовая и оптическая электроника» (адреса /kioe/lab/<N>,
  API /api/kioe/...), все три работы полностью реализованы:

    № 1 «Исследование основных параметров полупроводникового лазера»:
      – Таблицы 1.1 и 1.2: ввод U_ПЛ (мВ), I_ФП (мкА), I_max/I_min (мкА);
        расчёт I_pn = U_ПЛ/R1, степени поляризации P.
      – Аппроксимация ВАХ двумя прямыми: пороговый ток I_пор,
        коэффициенты k_св и k_лаз, R² обоих режимов.
      – Поле «Ввести значения» рядом с кнопкой «Построить зависимость
        I_ФП(I_pn)»: пользователь указывает точки красной линии лазерного
        режима — номерами строк таблицы («10», «10-18», «10,12,14-18»)
        или координатами парами «x;y» («2.45;70 2.6;209»). После повторного
        нажатия кнопки график перестраивается: красная линия проводится
        по МНК из выбранных точек (чтобы прошла по колену характеристики),
        параметры и I_пор пересчитываются. Точки, вошедшие в подгонку,
        выделяются на графике (зелёные — светодиодный, жёлтые с красной
        каймой — лазерный режим), у каждой экспериментальной точки
        подписаны значения «x; y».
      – График P(I_pn) размечается режимами: вертикаль на I_пор
        (берётся из последнего построения части 1), зелёная область
        светодиодного режима (P мал) и красная область лазерного
        режима (P возрастает); в Excel-файл добавляется строка I_пор.
      – Графики I_ФП(I_pn) и P(I_pn) с кнопками PNG / EXCEL.
      – Excel-файлы KIOE содержат живые формулы: параметры подгонки —
        =НАКЛОН(...)/=ОТРЕЗОК(...)/=RSQ(...) по диапазонам ячеек данных
        (в файле — SLOPE/INTERCEPT/RSQ, русский Excel показывает
        локализованные имена), I_пор — формулой пересечения прямых,
        колонки линий — формулами k·x+b со ссылками на ячейки параметров,
        в P(I_pn) — I_pn = U_ПЛ/R1 и P = (I_max−I_min)/(I_max+I_min)
        формулами; в лаб. 2 — I/I0, ASIN(SQRT(...)), DEGREES, U_λ/2 = π/(2m),
        r_33 = 1000·2·m·λ·d/(π·n0³·l) (пм/В) формулами; в лаб. 3 —
        τ = U*_ФД/U_ФД, линейная аппроксимация и τ опорное (=МЕДИАНА)
        формулами. При открытии книги пересчитываются (fullCalcOnLoad).

    № 2 «Определение электрооптических параметров анизотропных кристаллов»
      (LiNbO3, эффект Поккельса):
      – Таблица (U, I); расчёт I/I0 и arcsin√(I/I0) — отношение I/I0 под
        корнем; графики I(U) с аппроксимацией — обратное преобразование I = I0·sin²(m·U + b) со знаковыми m, b (кривая проходит через точки на любой ветви; при m<0 — убывание от максимума при U=0), U_λ/2 и r — по |m|; и
        линеаризация arcsin√(I/I0) = f(U).
      – Полуволновое напряжение U_λ/2 = π/(2m), электрооптический
        коэффициент r = 2mλd/(π·n0³·l), сравнение с табличным r_33.

    № 3 «Полупроводниковые детекторы оптического излучения» (ФД-24К):
      – Таблица 3.1 (фотогальванический режим, нагрузки R1 и R2) и
        таблица 3.2 (фотодиодный режим, смещение U_см): U_ПЛ, U_ФД, U*_ФД;
        расчёт I_pn и пропускания светофильтра τ = U*ФД/U_ФД.
      – Три графика U_ФД(I_pn) и τ(I_pn); диапазон линейности определяется
        по постоянству τ; чувствительность a, R², автоматические выводы.

• Курс «Вакуумная и плазменная электроника» (адреса /vipe/lab/<N>,
  API /api/vipe/...):

    № 1 «Исследование термоэлектронной эмиссии» — полностью реализована:
      – Паспортные данные диода: d_к, l_к (для удельной мощности накала),
        l_а (для площади эмиссии S = π·d_к·l_а), r_к и r_а (для поля
        коаксиального диода E = U_а/(r_к·ln(r_а/r_к))).
      – Для 2–5 накалов вводятся I_н (А), U_н (В) и таблица ВАХ (U_а, В;
        I_а, мА). Есть кнопка «Заполнить демонстрационными данными».
      – Обработка (кнопка «Рассчитать и построить графики»):
          * ток эмиссии I_Э — точка перегиба каждой ВАХ (кусочно-линейная
            аппроксимация, точка пересечения двух прямых);
          * плотность тока эмиссии j = I_Э/S;
          * удельная мощность накала P = I_н·U_н/(π·l_к·d_к) и температура
            катода T по модельной калибровке вольфрама P = ε(T)·σ·T⁴
            (ε = 0,25 при 2000 К … 0,32 при 3000 К); ток единичного катода
            I′_н = I_н/d_к^1.5 — для метода сравнения;
          * прямая Ричардсона ln(j/T²) = f(1/T): работа выхода
            eφ = |наклон|·k/e (эВ) и константа Ричардсона A = exp(отрезок);
          * прямые Шоттки ln j = f(√E) по точкам ВАХ правее перегиба:
            температура катода по наклону T = (e³/4πε₀)^½/(k·B);
          * результаты сводятся в таблицу (аналог табл. 3.2 методички) и
            дополняются автоматическими выводами.
      – Четыре графика с кнопками PNG / EXCEL: семейство ВАХ с точками
        перегиба; прямая Ричардсона; прямые Шоттки; зависимость j = f(T)
        с модельной кривой Ричардсона–Дешмана.

    № 2 «Исследование электронно-лучевой трубки с магнитным
    управлением» — полностью реализована:
      – Параметры установки: три значения U_а для модуляционных
        характеристик, U_а номинальное, ток I_реф для проницаемости,
        число витков и средний диаметр фокусирующей катушки (N_ф = 2500,
        70 мм), витки отклоняющих катушек (N_о = 200), протяжённость
        поля a, диаметр горловины d, расстояние линза–экран L.
      – Пять таблиц ввода: модуляционные характеристики I_к(U_м) при
        трёх U_а; ток фокусирующей катушки I_ф(U_а); отклонение пятна
        D от тока катушек (верт./гор.); отклонение D от U_а; яркость
        экрана (фототок) от тока луча и от U_а.
      – Обработка:
          * крутизна модуляционной характеристики S = ΔI_к/ΔU_м
            (МНК по рабочему участку кривой при U_а ном);
          * проницаемость модулятора Δ = −ΔU_м/ΔU_а при I_к = I_реф
            (интерполяция U_м на каждой кривой + МНК);
          * фокусное расстояние магнитной линзы f = 10·√(U_а·R)/(N_ф·I_ф)
            (ф. 2.3, R в см, f в см) — по каждой точке и в среднем,
            график I_ф(U_а) с моделью N·Y = 10·√(U·R)/f;
          * чувствительность катушек ε = D/(N_о·I_отк) в мм/ампервиток
            по наклону D(I_отк) и теоретическая
            ε_теор = a·L/(2.7·√U_а·d) (из ф. 2.5);
          * зависимость D(U_а) при постоянном токе катушек — модель
            D = c/√U_а (D ∝ 1/√U_а);
          * яркость: линейная аппроксимация J(I_л) и степенная J = c·U_а^p.
      – Пять графиков с кнопками PNG / EXCEL (последний — с двумя
        панелями; книга Excel с двумя листами).

    № 3 «Исследование фотоэлектронных приборов» — полностью реализована:
      – Приборы: электронный (вакуумный) и ионный (газонаполненный)
        фотоэлементы, однокаскадный фотоумножитель ФЭУ-1.
      – Параметры установки: U_а номинальное (200 В), U_а участка насыщения
        ионного для расчёта K_г (120 В), три анодных напряжения световых
        характеристик (100/150/200 В), U_э номинальное ФЭУ (90 В),
        нагрузка R_н (5 МОм), потоки для характеристик ФЭУ F_1/F_2
        (240/420·10⁻³ лм). Световой поток — позиции переключателя лампы
        80…420·10⁻³ лм (таблица 3.1 методички).
      – Восемь таблиц ввода: утомление фотокатодов трёх приборов (одна
        таблица, t = 0…14 мин); анодные характеристики электронного
        фотоэлемента при пяти потоках; анодные характеристики ионного
        при двух потоках; световые характеристики фотоэлементов
        (F + 3 колонки электронного + 2 ионного); световые характеристики
        с нагрузкой R_н (все три прибора); световые характеристики ФЭУ
        I_к(F) и I_а(F); эмиттерные характеристики ФЭУ I_а(U_э) при двух
        потоках; анодные характеристики ФЭУ I_а(U_а) при двух потоках.
      – Обработка (кнопка «Рассчитать и построить графики»):
          * кривые утомления: начальный и конечный фототок, спад в %;
          * интегральная чувствительность K_F = I_а/F (мкА/лм) — МНК-наклон
            световой характеристики в насыщении (электронный), среднее
            I_а/F (ионный — характеристика нелинейна);
          * чувствительность по напряжению K_н = (I_а/F)·R_н (В/лм) по
            характеристикам с нагрузкой для всех трёх приборов;
          * коэффициент газового усиления K_г = I_г/I_нас ионного
            (интерполяция токов на ВАХ при U_а ном и U_а нас) и крутизна
            ВАХ в рабочей точке (мкА/В);
          * ФЭУ: K_F фотокатода, K_ум фотоумножителя, σ = K_ум/K_F,
            среднее I_а/I_к;
          * зависимость σ(E = e·U_э) из эмиттерных характеристик с
            нахождением максимума (п. 4.2.7 отчёта);
          * крутизны эмиттерной и анодной характеристик ФЭУ в рабочих
            точках (мкА/В).
      – Девять графиков с кнопками PNG / EXCEL: утомление (3 кривые),
        ВАХ электронного (5 кривых), ВАХ ионного (2 кривые), световые
        характеристики фотоэлементов (5 кривых), световые с нагрузкой
        (3 кривые), световые ФЭУ (I_к и I_а), эмиттерные (2 кривые),
        анодные ФЭУ (2 кривые), σ(E) (2 кривые).

Установка и запуск
------------------
1. Установите зависимости (один раз):
       pip install -r requirements.txt

2. Запустите приложение:
       python app.py

3. Браузер откроется автоматически по адресу http://127.0.0.1:5000
   Если этого не произошло — откройте адрес вручную, выберите курс,
   затем лабораторную работу.

4. Для остановки приложения нажмите Ctrl+C в консоли.

Работа с программой
-------------------
• На главной странице кликом по названию курса секция сворачивается/
  разворачивается. Карточки работ открываются в новой вкладке.
• Лабы КИОЭ № 1–3 и лаба ВиПЭ № 1: заполните таблицы (или нажмите кнопку
  «Заполнить демонстрационными данными»), затем кнопку расчёта/построения
  графиков. Пустые строки игнорируются; для графиков нужно минимум
  необходимое число точек (см. сообщения об ошибках).
• Графики сохраняются кнопками PNG (картинка) и EXCEL (книга .xlsx
  с таблицей данных, параметрами и встроенной диаграммой).
• Все расчёты выполняются локально, без доступа к интернету.
