# LabApp
Лабораторный практикум - локальное веб-приложение для ввода данных эксперимента, автоматического расчета и построения графиков. Для лабораторных работ студентов ТУСУР направления промышленной электроники.

## Технологии
Flask (веб-интерфейс), numpy (расчеты и аппроксимация), matplotlib (графики PNG), openpyxl (Excel-файлы .xlsx с диаграммами).

## Возможности
«Расчетная часть» - во всех работах под блоком формул выводится таблица «формула = подстановка = ответ» со всеми расчетами: построчные вычисления (I_pn, I/I_0, arcsin√(I/I_0), τ, …), суммы и коэффициенты МНК (k, b, R^2), итоговые величины (I_пор, U_λ/2, r_33, τ опорное, линейный диапазон) и др.
